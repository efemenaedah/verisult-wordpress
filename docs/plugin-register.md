# Plugin and Theme Register

This register documents known project components. It is not an instruction to install every item. Confirm purpose, licence, compatibility and active use before installation or removal.

| Component | Role | Notes |
| --- | --- | --- |
| WordPress | Content management system | Keep core updated after staging validation |
| Upstudy Education | Legacy theme | Associated with original demo content and imported relationships |
| Upstudy Core | Legacy theme companion | Review before removing from any Upstudy-dependent page |
| One Click Demo Import | Demo importer | Disable/remove when imports are complete if no longer needed |
| Astra | Modernization parent theme | Use with the Verisult child theme |
| Elementor | Main visual page builder | Primary builder for general pages |
| Thrive Architect | Specialized landing-page builder | Required for the CAP landing page |
| Thrive Product Manager | Thrive product installer/manager | Required to install and maintain licensed Thrive products |
| Tutor LMS | Learning-management functionality | Confirm courses and templates before updates |
| Contact Form 7 | Form handling | Verify recipients, consent and spam protection |
| WP Events Manager | Event listings | Confirm active events and archive behaviour |
| Mailchimp for WordPress | Newsletter integration | Keep API credentials outside Git |
| Zoom integration | Online delivery support | Confirm account connection and meeting permissions |
| UpdraftPlus | Backup and recovery | Test restoration periodically |
| WP Staging | Staging environment | Keep redesign isolated from production |

## Review questions

- Is this component active and used by a live page?
- Does another component perform the same job?
- Is the licence current?
- Is the installed version compatible with the current WordPress and PHP versions?
- Is it included in backups?
- Does it store credentials or personal data requiring extra protection?
