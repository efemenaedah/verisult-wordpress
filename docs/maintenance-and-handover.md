# Maintenance and Handover

## Handover inventory

- Production and staging ownership
- Domain and DNS ownership
- Hosting support contact
- WordPress administrator roles
- Active theme and child theme
- Page-to-builder mapping
- Active plugin register
- Form recipients and test procedure
- Backup schedule and restoration procedure
- Analytics and search-console ownership
- Renewal dates for licensed products

Do not place credentials or recovery codes in this public repository. Use the organization’s approved password manager.

## Page ownership register

| Page type | Expected editor |
| --- | --- |
| Homepage and general pages | Elementor |
| CAP landing page | Thrive Architect |
| Posts and simple content | WordPress editor, unless documented otherwise |
| Course content | Tutor LMS and/or the documented page builder |

Confirm the actual editor before changing any existing page.

## Routine maintenance

### Weekly

- Confirm successful backups.
- Review form delivery and obvious broken pages.
- Apply urgent security updates after risk review.

### Monthly

- Test updates in staging.
- Review WordPress Site Health.
- Check broken links, forms and mobile navigation.
- Remove unused administrator accounts and expired content.

### Quarterly

- Test a backup restoration.
- Review plugin necessity and licences.
- Audit accessibility, performance and SEO basics.
- Confirm program, schedule, price and employer information remains accurate.

## Change record

Every material change should identify:

- Date
- Owner
- Page/component changed
- Reason
- Staging test completed
- Approval
- Production deployment result
- Rollback reference
