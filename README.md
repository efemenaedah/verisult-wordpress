# Verisult College WordPress Website

## Project purpose

Verisult College is a career-focused training institute that helps newcomers, career changers and underemployed professionals translate existing experience into employable skills, recognized certifications and project-ready capability.

The website is organized around four service pillars:

1. Career development and employment support
2. Upskilling and professional training
3. Certifications
4. Employer and workforce solutions

The core homepage message is:
> Get Trained. Get Hired. Deliver Projects.

## Step-by-step project process

### 1. website setup and configuration

1. DNS and hosting configuration
2. Wordpress installation

### 2. Prepare staging

1. Create or refresh the WordPress staging copy with WP Staging.
2. Confirm that staging cannot be indexed by search engines.
3. Verify that changes made in staging do not modify production.

### 3. Establish the frontend foundation

1. Configure global colours, typography, buttons, container widths and spacing.
2. Use Elementor Free for the main site pages.
3. Retain Thrive Architect only where required, particularly the CAP landing page.


### 4. Build the homepage

Recommended section order:

1. Hero — “Get Trained. Get Hired. Deliver Projects.”
2. Four service pillars 
3. Five-step career journey
4. Featured programs and certifications
5. Career support and success stories
6. Employer and community partnership section
7. EPIC values
8. Final call to action
9. Footer 

Other Links:

- About
- Programs
- Career Services
- Certifications
- Employers
- Community
- Contact
- Privacy Policy
- Individual course pages

### 5. Migrate the CAP landing page

1. Confirm Thrive Architect is installed and licensed in staging.
2. Export the landing page from the source WordPress environment.
3. Import it into a new draft page in staging.
4. Check fonts, images, links, forms and responsive styling.

### 6. Build course and certification content

1. Use a reusable structure for learning outcomes, audience, prerequisites, delivery, schedule, cost and registration.
2. Check desktop heading visibility, responsive ordering, text colour and container spacing.
3. Confirm all dates, prices and registration links immediately before publication.

### 7. Configure forms and integrations

1. Build learner, consultation and employer forms using the approved form plugin.
2. Test validation, confirmation messages and email delivery.
3. Confirm Mailchimp, Zoom and event integrations only where needed.

### 8. Complete responsive and accessibility QA

- Desktop, laptop, tablet and mobile compatibility test
- Heading hierarchy and colour contrast test
- Header, dropdown and mobile menu behaviour test
- Buttons, internal links and external links test

### 9. Review staging

1. Compare staging against the approved content and design direction.
2. Obtain stakeholder approval.
3. Record known limitations and rollback instructions.
4. Create a fresh production backup immediately before launch.

### 10. Deploy to production

1. Deploy only approved files and content.
2. Recheck forms, menus, SSL, responsive behaviour and analytics.
3. Monitor the site after launch and retain the pre-launch backup.

### 11. Handover and maintenance

1. Give each administrator an individual account with the least required privilege.
2. Document the active theme, page builders and plugin responsibilities.
3. Schedule backups and test restoration periodically.
4. Review forms, links, course dates and employer information regularly.
