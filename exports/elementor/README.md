# Elementor Exports

Store only approved and sanitized Elementor template or site-kit exports here.

Before committing an export:

1. Confirm it contains no credentials, private URLs, personal data or form submissions.
2. Give it a descriptive name such as `homepage-hero-v1.json`.
3. Record its source page and export date in the pull request.
4. Import it into staging and test it before production use.

Elementor stores most live page content in the WordPress database. These exports supplement backups; they do not replace them.
