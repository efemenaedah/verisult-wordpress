# Verisult Astra Child Theme

This child theme provides project-owned frontend assets while Astra remains the parent theme.

## Installation

1. Install and activate the Astra parent theme.
2. Copy `verisult-astra-child` into `wp-content/themes/`.
3. Activate **Verisult Astra Child** in WordPress.
4. Clear all caches.
5. Confirm the header, menus and Elementor pages in staging.

Do not place environment credentials, exported databases or third-party commercial assets in this directory.
